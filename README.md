# Lava Run — игра для Roblox без компьютера

Весь мир строится кодом. Студия не нужна: меняешь файл — GitHub сам собирает плейс и публикует его в твой опыт.

## Что внутри игры

Обби над лавой: 18 этапов, чекпоинты, монеты, движущиеся платформы, вращающиеся лезвия, магазин прокачки (скорость, прыжок, магнит, удача) и сохранение прогресса.

## Файлы

| Файл | Зачем |
| --- | --- |
| `src/Config.lua` | все настройки: этапы, цены, скорость, цвета |
| `src/GameServer.server.lua` | сервер: строит трассу, считает монеты, хранит прогресс |
| `src/GameClient.client.lua` | интерфейс: счётчики, магазин, кнопки |
| `place.json` | числа твоего опыта (universeId и placeId) |
| `build_place.py` | собирает файл плейса из скриптов |
| `tools/lua_lint.py` | проверяет Lua перед публикацией |
| `scripts/publish.sh` | отправляет плейс в Roblox |
| `docs/publish-workflow.yml` | заготовка автоматизации для копирования |
| `LAST_PUBLISH.md` | отчёт о последней публикации |

## Разовая настройка

1. Создай файл автоматизации: открой `docs/publish-workflow.yml`, скопируй всё,
   затем Add file -> Create new file, имя `.github/workflows/publish.yml`, вставь и сохрани.
2. Создай ключ на `create.roblox.com/dashboard/credentials`, вкладка API Keys.
   Право: **Place Publishing**, операция **Write**, опыт — твоя игра. Ключ показывают один раз.
3. Settings -> Secrets and variables -> Actions -> New repository secret.
   Имя: `ROBLOX_API_KEY`, значение: ключ.
4. Actions -> «Публикация плейса» -> Run workflow.

## Как менять игру

Правишь любой файл в `src/` и жмёшь Commit — через минуту игра обновлена.
Самое простое — `src/Config.lua`: число этапов, цены в магазине, скорость бега.
Хочешь черновик вместо живой игры — поставь в `place.json` значение `"versionType": "Saved"`.

## Если что-то пошло не так

Открой `LAST_PUBLISH.md` — там лежит ответ Roblox.

| Код | Что делать |
| --- | --- |
| 401 | ключ неверный или просрочен — создай новый |
| 403 | у ключа нет права Write на этот опыт |
| 404 | неверные числа в `place.json` |
| 400 | часто временный сбой Roblox — запусти ещё раз |
| 429 | слишком часто — подожди минуту |
